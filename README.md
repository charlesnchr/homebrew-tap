# Homebrew Tap

Custom Homebrew formulae and casks.

## Install

```bash
brew tap charlesnchr/tap
```

## Available Formulae

### Bento

Menu-bar app for screenshots, window management, clipboard, notes and todos (Apple Silicon, macOS 14+). Installs to `/opt/homebrew/opt/bento/Bento.app` and updates itself from its menu.

```bash
brew install charlesnchr/tap/bento
open /opt/homebrew/opt/bento/Bento.app
```

## Available Casks

### LLMux

Universal LLM gateway — query ChatGPT, Claude, and Gemini simultaneously.

```bash
brew install charlesnchr/tap/llmux
```
